# 公式LINE 定型文（あいさつ・案内）

LINE Official Account Manager に貼り付けて使う文面集です。
会名・URL・QR等は実値に差し替えてください。配信ルール（設計書 §3.4）：1通2スクロール以内／絵文字2個まで／敬体統一。

---

## ① 友だち追加時のあいさつメッセージ

> 設計書 §3.1：登録御礼＋MS紹介1行＋サイトリンク＋「体験参加希望」案内。会員向けに登録のお願いと、AIの使い方を追記。

**⚠ 友だち追加時のあいさつは、この1通だけにすること。**
2026/09/01 まで、LINE側のあいさつメッセージと Webhook（`aoi` の `follow` イベント）の
両方が送られ、**2通届いていた**。Webhook側の返信は削除済み
（`aoi/src/app/api/line/webhook/route.ts`）。**`follow` での返信を復活させないこと。**

冒頭の `{ユーザーの表示名}` は Official Account Manager の「友だちの表示名」タグ。
手打ちではなく、編集画面の挿入ボタンから入れる。

```
{ユーザーの表示名}さん
はじめまして。【公式】岡崎市葵倫理法人会です。
友だち追加ありがとうございます。

当会では毎週木曜 朝6:00〜7:00、イズモホール岡崎貴賓館にて
経営者モーニングセミナーを開催しています（はじめての方も参加無料・予約制）。

▼ 講師予定・会場・体験参加のご案内はこちら
https://okazaki-aoi.vercel.app/

■ はじめて参加してみたい方（体験参加）
このトークに「体験参加希望」と送ってください。担当より日程をご案内します。

■ 会員の方
下のメニュー「会員登録」から、お名前・役職・委員会のご登録をお願いします。
（出欠連絡や委員会のご案内に使用します）

■ ご質問はこのトークにそのままどうぞ
AIが、登録済みの資料をもとにお答えします。
例）モーニングセミナーは何時からですか／駐車場はどこですか
```

```

下のメニュー「会員登録」をタップ → お名前・倫理法人会での役職・所属委員会をご入力ください。

```

## ④ 体験参加希望キーワードへの自動応答

> **2026/09/01：チャットボット（`aoi`）側に実装済み。LINE管理画面の設定は不要です。**
> 「応答メッセージ」機能はオフ（AIの回答と二重になるため）なので、キーワード自動応答は
> `aoi/src/app/api/line/webhook/route.ts` の `TRIAL_KEYWORDS` / `TRIAL_MESSAGE` で返しています。
> **文面を変えるときは、下の本文とコードの両方を直してデプロイ**してください。
>
> 拾う言葉（前後に文字が付いていても拾う。例「体験参加希望です」）：
> `体験参加希望` / `体験参加` / `体験希望` / `見学希望` / `参加希望`
> これらを含むメッセージは AI に通さず、下の定型文を即返します（夜間・早朝でも一次受けできます）。

```
体験参加のお申し込み、ありがとうございます。
担当より、あらためてご案内いたします。

◎開催：毎週木曜 6:00〜7:00
　（活力朝礼は5:30〜。朝礼からの見学も歓迎です）
◎会場：イズモホール岡崎貴賓館
　〒444-0802 愛知県岡崎市美合町小豆坂91（駐車場あり）
◎費用：見学は無料です。朝食会（7:15〜）も初回は無料です
◎服装：普段のお仕事の服装で構いません

ご都合のよい日がお決まりでしたら、「9月10日」のようにこのトークへお送りください。
まだ決まっていなければ、このままお待ちください。担当からご連絡いたします。

▼ 講話者の予定はこちら
https://okazaki-aoi.vercel.app/

お急ぎのときは、お電話でも承ります。
専任幹事 石本 090-4183-9663
```

⚠ この定型文が返っても、**担当への通知は飛びません。** LINEのトーク一覧に未読として残るだけなので、
申し込みの取りこぼしを防ぐには、公式LINEのトークを日次で見る運用が要ります。

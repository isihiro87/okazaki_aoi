# 公式LINE プロフィールアイコン

LINE公式アカウントのアイコン画像。**採用したのは岡崎城**。

| フォルダ | 状態 | 中身 |
|---|---|---|
| `okazaki-castle/` | **採用** | 岡崎城 天守の写真を切り抜いたもの |
| `rinri-badge/` | 保管（不採用） | 倫理研究所の社章を組んだもの。全国共通の紋章のため見送り |

原本の写真・ロゴは `docs/18_画像素材/` にある。

## 共通の注意

### LINEのアイコンは円形に切り抜かれる

正方形で作っても、表示されるのは**内接する円だけ**。四隅は必ず落ちる。
どちらのフォルダの `build.py` も、この前提で構図・余白を決めている。

`*_circle.png` は「LINEでどう見えるか」の確認用。**これをアップロードしない。**

### 実寸は思っているより小さい

トーク一覧では 40〜60px しかない。`_preview_sizes.png` で
40 / 60 / 96 / 140px を並べてあるので、変更したら必ずここで確認すること。

### アップロード手順

```
LINE Official Account Manager（manager.line.biz）
  → 設定 → アカウント設定 → 基本情報 → プロフィール画像
```

推奨 640×640px。反映まで時間がかかることがある。

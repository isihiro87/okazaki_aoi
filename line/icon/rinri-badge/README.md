## なぜ余白を空けているか

**LINEのアイコンは円形に切り抜かれる。** この社章は白い三角形の3つの頂点が
黄色い花弁の円より外に出ているため、全面に配置すると**上・左下・右下が削られる**。

元画像（512px）の実測で、中心から最も遠い不透明画素は **半径276px**。
画像の内接円は半径256pxなので、**20px はみ出す**。

そこで紋章を 504px に収め、640px の画布の中央へ置いている。
これで紋章の最大半径は円の **85%** に収まり、どの機種でも切れない。

倍率は 0.984 倍（ほぼ原寸）なので、拡大による劣化は無い。

## なぜ藍色を勧めるか

40〜60px（トーク一覧の実寸）で見比べると差が出る。

- 生成り・白 … 紋章の外周が背景に溶け、輪郭が定まらない
- **藍** … 濃い円が輪郭になり、金の花弁と白い三角が浮き上がる

社章の白い三角形は `#eff1f3` とほぼ白なので、明るい背景では細い輪郭線しか
頼るものが無い。藍にすると三角がそのまま白い面として効く。

## ⚠ 元画像について

`docs/18_画像素材/倫理研究所_社章.png` を使用。元のファイル名のとおり
**神奈川県倫理法人会のサイトから取得したもの**で、512px のラスタ画像。

正式には、**県事務局または倫理研究所から公式データ（できればベクター）を受け取ること。**
他単会のサイトの画像を単会の公式アカウントの顔にするのは、体裁として避けたい。
公式データが入手できたら、下の再生成コマンドで作り直せる。

## 作り直し方

```bash
cd rinri
python official_line/line/icon/build.py <元画像のパス>
```

## アップロード手順

```
LINE Official Account Manager（manager.line.biz）
  → 設定 → アカウント設定 → 基本情報 → プロフィール画像
```

推奨 640×640px。変更後、反映まで少し時間がかかることがある。

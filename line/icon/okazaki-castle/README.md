# 公式LINEアイコン（岡崎城）★採用

| ファイル | 用途 |
|---|---|
| **`icon.png`** | **アップロードするのはこれ**（640×640 / PNG） |
| `icon.jpg` | 同じもののJPG版。容量を抑えたいとき |
| `icon_circle.png` | LINEでの見え方の確認用。**アップロードしない** |
| `_preview_sizes.png` | 40 / 60 / 96 / 140px の見比べ |
| `build.py` | 作り直し用 |

原本は `docs/18_画像素材/岡崎城_天守.jpg`（1560×1050）。

## 切り抜きの決め方

LINEのアイコンは円形に切り抜かれるので、**円の中で成立する構図**にする必要がある。
天守を中心に、一辺 520 / 590 / 640 / 700 / 760px の候補を円形マスクで見比べ、
**700px（中心 770,600）** を採った。

| | |
|---|---|
| 狭すぎる（520〜590） | 天守が窮屈で、上の鯱が円の縁に当たる |
| **700（採用）** | **天守の全体が入り、上に空、下に緑が少し残る** |
| 広すぎる（760〜900） | 天守が小さくなり、40pxで何の建物か分からなくなる |

コントラストと彩度をわずかに上げている（1.06 / 1.04）。
小さく表示したときに屋根と空の境目が溶けないようにするため。強くしすぎると不自然になる。

## 作り直し方

```bash
cd rinri
python official_line/line/icon/okazaki-castle/build.py
```

切り抜き位置を変えるなら `build.py` の `CROP` を編集する。
変更後は必ず `_preview_sizes.png` の 40px を見ること。**大きい画面では判断できない。**

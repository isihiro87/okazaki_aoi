# 活動報告カードの挿絵 — 作業指示書

公開サイト（`okazaki-aoi.vercel.app`）の「活動報告」に出す挿絵を **3枚** 作ります。

いまは CSS のグラデーション（藍→紫→桃）で埋めていますが、**生成AIらしく見える**ため、
落ち着いた線画に差し替えます。

## 出力

| | |
|---|---|
| 保存先 | `img/reports/<ファイル名>.png`（作業ディレクトリは `official_line`） |
| サイズ | **1200 × 630 px**（横長） |
| 背景 | **生成り `#faf7f1` のベタ塗り**。透明にしない |
| 枚数 | 3枚 |

## 絵柄

サイトは「夜明け」がテーマで、明朝体・藍色・生成りで組んだ静かな見た目です。それに合わせます。

| | |
|---|---|
| 線 | **藍色 `#1b2a4a` の一色**。太さはほぼ一定（1200px 中で 3〜4px）。手で引いたようにわずかに揺れてよい |
| 塗り | **面で塗らない。** 線だけで描く。必要なら細い平行線（ハッチング）を控えめに使ってよい |
| 色 | **藍 `#1b2a4a` と生成り `#faf7f1` の2色だけ。** 差し色は使わない |
| 人物 | **顔を描かない。** 遠景の人影・後ろ姿・シルエットに近い簡略な線で。特定の個人に見えないこと |
| 雰囲気 | 静かで端正。線が細く、余白が多い。**版画や建築のスケッチに近い** |
| 余白 | 上下左右に 60px 程度の余白を残す |

### やってはいけないこと

- **文字・数字を一切描かない**（日本語は必ず崩れます）
- **グラデーション・影・写実的な陰影・写真的表現**（これを避けるための作り直しです）
- 顔の描写、実在の人物・企業ロゴ・宗教的シンボルを思わせるもの
- 賑やかな装飾、鮮やかな色、光のにじみ、ぼかし

## 3枚の中身

### 1. `img/reports/report-lecture.png` — 倫理経営講演会

広いホール。奥の壇上に**四角い演台**がひとつ。手前は客席に座った人の**後ろ姿が並ぶ**（顔は見えない）。
天井の高さが分かるように、奥行きのある構図。人は多めだが、線は細く静かに。

### 2. `img/reports/report-venue.png` — 会場（イズモホール岡崎貴賓館）へ移転

朝の建物の外観。**低く横に広い建物**と、その前の**広い駐車場**。
車は数台、簡略な線で。空は白いまま（線を引かない）。左右どちらかから**朝の光の線**を数本だけ引く。
人は入れても1〜2人、遠景で小さく。

### 3. `img/reports/report-founding.png` — 設立総会・記念式典

式典の壇上。**背の高い置き型の看板や旗**を思わせる縦長の形がひとつ。
その前に**人が横一列に並んで立っている**（後ろ姿ぎみ、顔は描かない）。
手前に客席の頭が少しだけ入る。祝いの場だが、**紙吹雪やきらめきは描かない**。

## 終わったら

3枚のファイル名・サイズ・背景色を一覧で報告してください。

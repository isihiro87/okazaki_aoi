# 岡崎市葵倫理法人会 デジタル基盤（okazaki_aoi）

公開サイトと公式LINE実装一式。設計は [`設計書.md`](./設計書.md) を参照。

- 公開URL: https://okazaki-aoi.vercel.app/
- ホスティング: Vercel（GitHub の `main` に push すると自動で公開されます）

## 構成

| パス | 内容 |
|---|---|
| `index.html` / `css/` / `js/` | 公開サイト本体 |
| `js/data.js` | **広報委員が編集する唯一のファイル** |

| `設計書.md` | Webサイト・LINE・連携・運用の統合設計書 |

## 公開サイトの更新（広報委員の作業）

**`js/data.js` だけを編集します。** `index.html` `css/style.css` `js/render.js` は触りません。

```js
const SCHEDULE = [
  { date:"2026-09-03", theme:"演題", affiliation:"会社名 役職",
    speaker:"氏名 氏", ruby:"ふりがな", role:"○○倫理法人会 会長" },
];
```

| 決まりごと | |
|---|---|
| 日付 | 必ず `"YYYY-MM-DD"`（西暦-月-日）。**曜日は自動で表示されます** |
| 終わった回 | **自動で隠れます。** 消さなくて構いません |
| 予定が空のとき | 「次回の木曜」を自動計算して表示し、一覧は「準備中」の案内に切り替わります |
| 更新のタイミング | 月1回、月末までに翌月分 |

`data.js` の各配列の役割:

| 配列 | 内容 |
|---|---|
| `SITE` | 会場・会費・電話・役員など。役員交代や会場変更のときだけ直します |
| `SCHEDULE` | 講話スケジュール（毎月更新） |
| `EVENTS` | 倫理経営講演会・経営者の集いなど、**会員以外も参加できる行事** |
| `REPORTS` | 活動報告カード。`image:"img/xxx.jpg"` で写真も出せます |
| `CHAIRMAN_MESSAGE` | 会長メッセージ。`text` に文章を入れると差し替わります |
